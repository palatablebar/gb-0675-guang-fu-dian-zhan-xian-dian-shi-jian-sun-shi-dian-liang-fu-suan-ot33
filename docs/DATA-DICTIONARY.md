# 功率与限电定义

设备额定功率为kW。遥测kW与MW统一为kW，辐照度为W/m²。样本时刻须带偏移，统一UTC。记录代表自采样时刻起600秒的左值保持区间，超过600秒不外推，缺测保持未定。
每台设备重叠或相邻限电事件先求并集，再按遥测及有效期边界切分半开区间。样例INV-A的10:00–10:20及10:10–10:30合并为30分钟，不能重复积分重叠10分钟。
基线只采用同区域、同采样时刻、同100W/m²辐照档、健康且不处于限电中的参考逆变器；至少2台。对参考功率按各自额定功率归一，取中位数再乘目标额定功率，基线不超过目标额定功率。无合格对照返回NO_REFERENCE及null损失，不填0。
每片段损失=max(基线−实际,0)×秒数/3600。实际高于基线时损失0。计算保留Decimal精度，汇总后统一保留0.0001kWh；未定时长单独展示，不并入已确定损失。
清批INV-A基线100kW、实际60kW、并集30分钟，损失20kWh；INV-B基线50、实际30、20分钟，损失6.6667kWh。总确定损失26.6667kWh。能量核验按实际+非负损失计算可解释基准电量。
同设备同一时刻不同观测全部隔离；同值重复观测保留稳定编号。封存需无隔离和未定片段。此工具供离线复算，不包含生产控制或电网调度。

## 混频采样裁定（2026-11-19）

采样间隔是设备级属性：`devices.<id>.cadence_seconds` 优先，缺省回落全局 `cadence_seconds`（600）。无设备级键的旧上下文行为与旧版逐位一致。

记录的左值保持窗口按本设备间隔计算。目标设备未被任何样本覆盖的分钟保持未定，不插值、不外推、不填0。

事件并集与积分时长只由事件记录决定，与采样频率无关；换频只改变切片粒度，不得改变并集边界与总秒数（时间守恒 `union_seconds==slice_seconds` 为跨频率不变量）。

基线对照取覆盖片段起点的各参考设备最新读数（读数在自身保持窗口内为有效证据）；参考的限电状态以其读数采样时刻为准。均匀同相频率下唯一命中片段起点处的读数，与旧版"同一采样时刻"逐位等价；参考窗口之外同样不外推。

重跑同批（同一输入快照）不得新增或改动已确认损失。频率参数属于上下文并参与批号摘要：换频生成新批次，旧批次保留；换频中断时用旧参数重算即命中旧批号，恢复旧版结果，无数据丢失。

损失页提供新旧批对照：按设备与事件并集对齐，展示确定损失差值与未定时段；对不上的并集单独列出，不计入对照合计。混频样例 `mixed`：东区 INV-A 及对照已换5分钟频且 INV-A 缺10:15样本（10:15–10:20未定300秒），西区保留10分钟旧频；确定损失23.3333kWh，与完整对照批差−3.3333kWh，恰为未定段。
